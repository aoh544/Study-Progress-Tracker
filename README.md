# Study Progress Tracker

학습 진도를 간편하게 기록하고, 목표 기간에 맞춰 현재 학습 페이스를 확인할 수 있는 웹 기반 학습 진도 관리 도구입니다.

## 주요 기능

- 최대 7개 과목 관리
- 과목별 수강 완료 강의 수 기록
- 전체 학습 진도율 자동 계산
- 오늘 기준 목표 진도 계산
- 목표 대비 진행 상태 확인
- 남은 기간 기준 일평균 필요 학습량 계산
- 과목별 진도 그래프 제공
- 브라우저 자동 저장
- JSON 데이터 백업 및 복원
- PC 및 모바일 환경 지원
- PWA 설치 및 오프라인 사용 지원

## 사용 방법

1. `Progress · Setup`에서 학습 계획을 설정합니다.
   - 시작일
   - 목표기간
   - 총 과목 수
   - 과목당 강의 수

2. 각 과목의 이름과 현재까지 완료한 강의 수를 입력합니다.

3. `Dashboard`에서 전체 학습 진도와 목표 대비 페이스를 확인합니다.

입력한 데이터는 사용 중인 브라우저에 자동 저장됩니다.

## 데이터 및 개인정보

Study Progress Tracker는 별도의 회원가입이나 서버 데이터베이스를 사용하지 않습니다.

사용자가 입력한 학습 정보는 브라우저의 Local Storage에 저장되며, 외부 서버로 전송되지 않습니다.

브라우저 데이터를 삭제하거나 저장 공간을 초기화할 경우 학습 기록이 삭제될 수 있으므로 필요한 경우 JSON 백업 기능을 이용해 주세요.
